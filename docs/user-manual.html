แพลตฟอร์ม "ก้าวใหม่" (KaoMai Web Application)

ระบบเชื่อมโยงคนไร้บ้านกับโอกาสงานและการดูแลรายกรณีแบบครบวงจร

เวอร์ชันระบบ: 1.0 (Branch: fixresponsive) ฐานข้อมูล: Supabase Cloud สำหรับ: ศูนย์คนไร้บ้าน & ผู้จ้างงาน

1. บทนำและภาพรวมระบบ

แพลตฟอร์ม "ก้าวใหม่" (KaoMai) พัฒนาขึ้นเพื่อเป็นสะพานเชื่อมโยงระหว่างคนไร้บ้านที่พร้อมทำงานกับผู้จ้างงานที่ต้องการแรงงาน โดยออกแบบระบบแบ่งตามบทบาทผู้ใช้งานชัดเจน 2 กลุ่ม:

  • พื้นที่ศูนย์คนไร้บ้าน (Shelter Admin / Case Manager): บันทึกข้อมูลและจัดเก็บเอกสารคนไร้บ้าน, มอบหมายผู้จัดการรายกรณี (CM), พิจารณาอนุมัติข้อเสนองาน และติดตามผลหลังเริ่มงาน
  • พื้นที่ผู้จ้างงาน (Employer): ลงประกาศงาน, คัดเลือกผู้สมัครจากคะแนนความเหมาะสม (Match Score %) และรับเบอร์ติดต่อเพื่อเริ่มงานเมื่อได้รับการอนุมัติ

2. คู่มือสำหรับศูนย์คนไร้บ้านและผู้จัดการรายกรณี

2.1 การจัดการข้อมูลผู้เข้าร่วม (Residents Manager)

เมนู: ผู้เข้าร่วม (/shelter/residents)

  1. กดปุ่ม "+ เพิ่มผู้เข้าร่วม" บริเวณมุมขวาบน
  2. ข้อมูลพื้นฐาน: อัปโหลดรูปถ่าย, กรอกชื่อที่ใช้แสดง, อายุ และเลือกเพศ
  3. โรคประจำตัว: กรอกข้อจำกัดสุขภาพ (ข้อมูลนี้จะถูกเก็บเป็นความลับเฉพาะศูนย์พักพิง และไม่แสดงแก่นายจ้าง)
  4. สถานะบัตรประชาชน: เลือกสถานะบัตร (มีบัตรประชาชน / อยู่ระหว่างดำเนินการ / ต้องการความช่วยเหลือ)
  5. รูปแบบงานที่ต้องการ: เลือก งานเต็มเวลา (Full-time) หรือ งานพาร์ทไทม์ (Part-time)
  6. วิธีรับเงินค่าจ้าง: เลือก เงินสด หรือ โอนเข้าบัญชีธนาคาร
  7. ทักษะและเวลา: เลือกทักษะที่มี พร้อมระบุวันและช่วงเวลาที่พร้อมทำงาน

2.2 การอัปโหลดเอกสารประกอบ (Supporting Documents)

  • รองรับประเภทไฟล์: PDF, JPG, PNG, WebP ขนาดไม่เกิน 5 MB ต่อไฟล์ (สูงสุด 5 ไฟล์ต่อคน)
  • เลือกประเภทเอกสาร: วุฒิการศึกษา, ใบรับรองการฝึกอบรม, ประวัติการทำงาน, เอกสารอื่น ๆ
  • สามารถกดเปิดดาวน์โหลดดูไฟล์ หรือกดลบเอกสารเดิมได้

2.3 แดชบอร์ดการดูแลรายกรณี (Case Management Dashboard)

เมนู: การดูแลรายกรณี (/shelter/case-management)

  • ดูสถิติภาระงานของผู้จัดการรายกรณี (Case Manager - CM) แต่ละคน
  • ตรวจเช็ครายชื่อที่ยังไม่ได้มอบหมายผู้จัดการ (Unassigned) เพื่อกดมอบหมายดูแล

2.4 การพิจารณาอนุมัติการจับคู่งาน (Match Approval)

เมนู: การจับคู่ (/shelter/matching)

  1. ข้อเสนอใหม่จากผู้จ้างงานจะอยู่ในสถานะ "ยื่นข้อเสนอแล้ว (Suggested)"
  2. เจ้าหน้าที่ศูนย์/CM ดำเนินการสอบถามความสมัครใจของผู้เข้าร่วม
  3. กดปุ่ม "อนุมัติการจับคู่" หากพร้อมเริ่มงาน (ระบบจะเปิดเผยเบอร์โทรศัพท์ติดต่อศูนย์/CM แก่ผู้จ้างงาน)
  4. กดปุ่ม "ไม่อนุมัติ / ผู้สมัครไม่สะดวก" หากผู้เข้าร่วมไม่สะดวกรับงาน

2.5 ระบบติดตามการทำงานและการยุติการทำงาน (Work Tracking)

เมนู: การติดตามงาน (/shelter/work-tracking)

  1. กดปุ่ม "+ เริ่มติดตามงาน" หลังเริ่มงาน
  2. สัปดาห์แรก: ติดตามบันทึกผลการทำงานรายวัน
  3. รอบติดตามถัดไป: เลือกระยะเวลาเป็น ทุก 2 สัปดาห์ (Fortnightly) หรือ ทุกเดือน (Monthly) ระบบจะคำนวณวันนัดถัดไปให้อัตโนมัติ
  4. การบันทึก Check-In: กด "บันทึกติดตาม" ระบุการมาทำงาน (ปกติ/สาย/ขาด) และการปรับตัว (ดี/ต้องการการสนับสนุน/เร่งด่วน)
  5. การยุติการทำงาน: กดปุ่ม "ยุติการทำงาน" เลือกเหตุผล กรอกสรุปปิดเคส และสามารถติ๊กเลือก "กลับเข้าสู่กระบวนการหางาน" เพื่อคืนรายชื่อพร้อมรับงานใหม่ได้ทันที
💡 คำแนะนำสำหรับการทดสอบระบบติดตามงาน

ทดลองกดบันทึกติดตามงานหลาย ๆ ครั้งเพื่อสังเกตประวัติย้อนหลัง (History Timeline) ทางขวามือ และทดลองกด "ยุติการทำงาน" พร้อมคืนกระบวนการหางาน

3. คู่มือสำหรับผู้จ้างงาน

3.1 การสร้างและลงประกาศงานใหม่

เมนู: ประกาศงานใหม่ (/employer/create-job)

กรอกชื่อตำแหน่งงาน รายละเอียด สถานที่ ค่าจ้างรายวัน (บาท/วัน) และเลือกทักษะที่ต้องการ แล้วกด "ลงประกาศงาน"

3.2 การคัดเลือกผู้สมัครและการยื่นข้อเสนอ (Smart Matching)

เมนู: ผู้สมัคร (/employer/matches)

  • แท็บ "ผู้สมัครแนะนำ": แสดงผู้สมัครเรียงตามคะแนนความเหมาะสม (Match Score %) และระยะทาง สามารถกดดูรายละเอียดโปรไฟล์ และกด "ยื่นข้อเสนองาน"
  • แท็บ "อนุมัติแล้ว/พร้อมเริ่มงาน": เมื่อศูนย์อนุมัติแล้ว ผู้จ้างงานจะสามารถกดดูเบอร์โทรศัพท์ติดต่อศูนย์/CM เพื่อเตรียมนัดหมายวันเริ่มงานได้ทันที

4. แบบฟอร์มการทดสอบระบบ (UAT Checklist)

หัวข้อการทดสอบ ขั้นตอนการทดสอบ ผลลัพธ์ที่คาดหวัง ผลทดสอบ
1. บันทึกคนไร้บ้าน เพิ่มคนไร้บ้านใหม่ + อัปโหลด PDF 1 ไฟล์ บันทึกสำเร็จ เอกสารเปิดดูได้ [   ] ผ่าน
2. มอบหมาย CM เพิ่มชื่อ CM และมอบหมายให้คนไร้บ้าน ชื่อและเบอร์ CM แสดงในโปรไฟล์ [   ] ผ่าน
3. สร้างประกาศงาน ผู้จ้างงานสร้างประกาศงานใหม่ งานแสดงในระบบ Matching [   ] ผ่าน
4. ยื่นข้อเสนองาน ผู้จ้างกด "ยื่นข้อเสนองาน" ศูนย์เห็นข้อเสนอในสถานะ Suggested [   ] ผ่าน
5. อนุมัติการจับคู่ ศูนย์กด "อนุมัติการจับคู่" ผู้จ้างเห็นเบอร์โทรติดต่อศูนย์/CM [   ] ผ่าน
6. เริ่มติดตามงาน ศูนย์กด "+ เริ่มติดตามงาน" เคสถูกสร้างในคิวติดตามงาน [   ] ผ่าน
7. บันทึก Check-In บันทึกมาทำงานปกติ และปรับตัว "ดี" ประวัติแสดงใน Timeline ย้อนหลัง [   ] ผ่าน
8. ยุติการทำงาน กด "ยุติการทำงาน" + ติ๊กคืนหางาน สถานะสลับเป็น Ended และคืนรายชื่อ [   ] ผ่าน
